Do & Don't.

Editorial guardrails. Anything beyond these requires a system update — not a one-off.

DO
  • Reach for tokens (var(--primary)) — never hex literals.
  • Start every section with eyebrow → headline → lead.
  • Use the three buttons. That's all.
  • Compose cards from --bg-card → --bg-card-2.
  • Test every new screen in both ink & dark modes.
  • Use the .field primitive for all form controls.
DON'T
  • Introduce new fonts. Sora, Inter, JetBrains Mono — final.
  • Add saturated blues, greens, reds outside the brand set.
  • Use pure #FFF or #000 — always token.
  • Draw decorative SVG illustrations from scratch.
  • Invent new shadow stacks or one-off radii.
  • Skip the .eyebrow → .h* → .lead rhythm.
