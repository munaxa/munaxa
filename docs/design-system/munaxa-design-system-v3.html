Munaxa Design System v3

The visual language for the Munaxa School OS — a violet/coral/aqua palette on deep indigo surfaces, geometric display type, and a bilingual EN/AR (LTR/RTL) layout system. v3 sets Cairo as the Arabic typeface and keeps the brand accents theme-aware so they stay legible in light mode. Toggle EN/ع and Dark/Light above to see everything live.

What's new in v3 CHANGELOG

  • Arabic typeface is now Cairo. When the page is in RTL/Arabic, --font-display and --font-body resolve to 'Cairo', sans-serif instead of Sora/Inter, which lack proper Arabic glyphs. Numbers/IDs in .mono remain JetBrains Mono and stay LTR.
  • Theme-aware accents. coral and aqua are now CSS variables, not fixed hex. Dark keeps full brightness (#FF8E6E / #4DF4E1); light switches to legible values (#D9534F / #0D9488). Tailwind alpha modifiers (text-coral/40) still work via hsl(var(--coral) / <alpha>).
  • Light theme is first-class. Full surface/border/text token set + the ☾/☀ switch in the app shell (persisted to localStorage).
  • Documented component tones — Badge (default/success/warning/danger/muted), Button variants, KPI stat card, the collections banner, and money formatting (mono, 3-dp JOD, always LTR).
  • RTL is a first-class mode, not an afterthought — logical properties throughout; numbers/IDs/dates stay LTR inside RTL.

Bilingual & RTL rules

  • Use logical properties (margin-inline-start, text-align:start, border-inline-end) — never hard left/right — so layouts mirror automatically.
  • Toggling to Arabic sets dir="rtl" on the document; the whole app flips, including the nav rail and tables.
  • Numbers, money, IDs, and dates stay LTR inside RTL text (direction:ltr;unicode-bidi:embed on the mono class).
  • Provide both nameEn and nameAr; the Arabic block is always dir="rtl", the English block always LTR, regardless of page direction.

Implementation

  • Tokens live in packages/config-tailwind/preset.ts + apps/admin/src/app/globals.css (HSL channels for theme-aware semantic + accent colors).
  • Fonts via next/font → --font-display (Sora, EN), --font-body (Inter, EN), --font-mono (JetBrains Mono). In RTL/Arabic, --font-display and --font-body switch to 'Cairo', sans-serif.
  • Theme switch: apps/admin/src/components/theme-locale-toggle.tsx toggles .dark on <html>, persisted to localStorage.
  • Shared UI kit: apps/admin/src/components/ui (Button, Card, Badge, Input/Select, Field, Table, Spinner).
